# キャラクターの画像差し替え（主人公）

主人公（プレイヤー）は既定ではコードでドット絵を生成して表示していますが、
ここに **スプライトシート** を置くと、そちらを優先して使います。

## 置き場所とファイル名

```
assets/characters/player.png
```

このファイルを追加してコミットするだけで反映されます（Web ビルドの CI が
自動でインポートします。ローカルで Godot を開く必要はありません）。
ファイルが無ければ、これまで通りコード生成の見た目にフォールバックします。

## レイアウト（4 列 × 3 行の等間隔グリッド）

1 枚の PNG に、以下の順でコマを並べてください。

```
        列0        列1        列2        列3
        待機A      待機B      歩きA      歩きB
行0  ┌─────────┬─────────┬─────────┬─────────┐  ← 下向き（正面）
     │         │         │         │         │
行1  ├─────────┼─────────┼─────────┼─────────┤  ← 上向き（後ろ姿）
     │         │         │         │         │
行2  └─────────┴─────────┴─────────┴─────────┘  ← 横向き（右向き）
```

- **行（上→下）**: 下向き ／ 上向き ／ 横向き
- **列（左→右）**: 待機A ／ 待機B ／ 歩きA ／ 歩きB
- **左向き**は横向き（行2）を自動で左右反転して表示します（用意不要）。
- 各コマは同じ大きさ。**画像の幅は 4 の倍数、高さは 3 の倍数**にしてください。
- 1 コマは **16×24 ピクセル相当が基準**（＝画像全体で 64×72）。別解像度でも
  背丈は自動で従来サイズに合わせます（例: 32×48/コマ＝画像 128×144 でも可）。
- 背景は透過（アルファ）で。足元が各コマの下端に来るように描くと位置が合います。

## レイアウトを変えたいとき

列数・行数・並び順はコードの定数で変更できます:
`scenes/CharacterArt.gd` の `SHEET_COLS` / `SHEET_ROWS` / `SHEET_ROW_DIRS`。
