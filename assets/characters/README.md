# キャラクターの画像差し替え（主人公）

主人公（プレイヤー）は既定ではコードでドット絵を生成して表示していますが、
ここに **スプライトシート** を置くと、そちらを優先して使います。

## 置き場所とファイル名

```
assets/characters/player.png
```

このファイルを追加してコミットするだけで反映されます（Web ビルドの CI が
自動でインポートします。ローカルで Godot を開く必要はありません）。
ファイルが無ければ、これまで通りコード生成の見た目にフォールバックします。

## レイアウト（10 列 × 3 行の等間隔グリッド）

1 枚の PNG に、以下の順でコマを並べてください。

```
        列0    列1    列2 … 列9
        待機A  待機B  歩き1 … 歩き8（歩きの1周期＝2歩）
行0  ← 下向き（正面）
行1  ← 上向き（後ろ姿）
行2  ← 横向き（右向き）
```

- **行（上→下）**: 下向き ／ 上向き ／ 横向き
- **列（左→右）**: 待機 2 コマ → 残り 8 コマが歩き
- **左向き**は横向き（行2）を自動で左右反転して表示します（用意不要）。
- 各コマは同じ大きさ。**画像の幅は 10 の倍数、高さは 3 の倍数**にしてください。
- 背丈は **1 コマの高さ** を 24px 相当として自動で合わせます（いまは 1 コマ 32×52＝画像 320×156）。
  キャラの頭がコマの上端近く、足元が下端に来るように切り抜くと大きさと位置が合います。
- 背景は透過（アルファ）で。

いまの `player.png` は LPC 素材を組み合わせたもの（出典・作者は `CREDITS.md`）。
差し替えたら `CREDITS.md` も更新してください。

## レイアウトを変えたいとき

列数・行数・並び順・歩きの速さはコードの定数で変更できます:
`scenes/CharacterArt.gd` の `SHEET_COLS` / `SHEET_ROWS` / `SHEET_ROW_DIRS` / `SHEET_IDLE_FRAMES` / `SHEET_WALK_CYCLE_SEC`。
