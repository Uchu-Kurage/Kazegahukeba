# Kazegahukeba（風が吹けば）

終わりゆく世界の最後の夏（8/31 に世界が終わる）を過ごす ADV 寄りの RPG。
このリポジトリは **まず「一日が回る骨組み」だけ** を動かすための最小構成です。
物語・キャラ・エンディングは、この骨組みが動いてから足していきます。

## いま動くもの（最小の核）

```
朝が来る → 午前の枠でどこへ行くか選ぶ → 午後の枠で選ぶ → 夜（振り返り）
        → カレンダーを1枚めくる → 翌日へ …（40日で世界の終わり）
```

- 40日間のカレンダー制（8/1 起点、`GameState.TOTAL_DAYS` で日数を調整可能）
- 一日 = 午前 / 午後（行動枠）＋ 夜（基本は振り返り）
- 行動枠では町のどこか一箇所を選ぶ＝その枠では他へは行けない
- 予定なしのスキップ（枠は消費する）
- 場所に紐づくキャラの関係値を +1 する仮ロジック（`GameState.affinity`）
- 40日を越えると「世界の終わり」画面 → 周回で再スタート

## 動かし方

1. **Godot 4.6** でこのフォルダ（`project.godot` のある場所）を開く。
2. 初回はアセットのインポートが走る（少し待つ）。
3. 右上の ▶ 実行（F5）でメインシーン `scenes/Main.tscn` が起動する。

> **日本語フォントについて**
> Godot 標準フォントは日本語を含まないため、`assets/fonts/NotoSansJP-Regular.ttf`
> （Noto Sans JP / SIL Open Font License 1.1）を同梱し、`project.godot` の
> `gui/theme/custom_font` で全体に適用しています。差し替えたい場合はこのファイルを
> 置き換えるだけで OK。

## ファイル構成

```
project.godot            プロジェクト設定（Autoload登録・メインシーン・フォント指定）
autoload/
  GameState.gd           ★状態の中心。日付・時間帯・好感度・フラグ＋一日を進める状態機械
data/
  Locations.gd           町の「場所」定義（当面は定数。後でリソース化してもよい）
scenes/
  Main.tscn / Main.gd    一日を回すループの司令塔（ビュー）。状態を見て画面を作るだけ
assets/fonts/
  NotoSansJP-Regular.ttf  日本語フォント（OFL 1.1）
```

## 設計の考え方（初心者向けメモ）

- **状態（モデル）と表示（ビュー）を分ける。** 日付や好感度は `GameState`（Autoload
  シングルトン）が唯一の持ち主。`Main.gd` はそれを見て画面を描くだけで、ロジックを
  持たない。こうしておくと、後で「別のUI」「セーブ／ロード」「エンディング」を足しても
  状態まわりを壊さずに済む。
- **一日 = フェーズの状態機械。** `午前 → 午後 → 夜 →（めくる）→ 翌朝` を `Phase` enum
  で一段ずつ進めるだけ。特別な夜イベントや、日ごとのイベント差し込みは、この1本の軸に
  ぶら下げていく。
- **シグナルで疎結合に。** 状態が変わったら `GameState` が `day_changed` /
  `phase_changed` を emit し、UI 側が受けて描画し直す。UI を増やしても購読するだけ。
