# Kazegahukeba（風が吹けば）

終わりゆく世界の最後の夏（8/31 に世界が終わる）を過ごす、2Dドットの ADV 寄り RPG。
このリポジトリは **まず「一日が回る骨組み」だけ** を動かすための最小構成です。
物語・キャラ・ドット絵・エンディングは、この骨組みが動いてから足していきます。

## いま動くもの（最小の核）

上から見た町マップを **2Dキャラで歩き回り**、誰かのところへ行って「調べる」と、
その時間帯の枠を消費して一日が進みます。

```
朝が来る → （午前）町を歩いて誰かのところで過ごす → （午後）もう一枠過ごす
        → 夜（振り返り）→ カレンダーを1枚めくる → 翌日 …（40日で世界の終わり）
```

- 40日間のカレンダー制（8/1 起点、`GameState.TOTAL_DAYS` で日数を調整可能）
- 一日 = 午前 / 午後（行動枠）＋ 夜（基本は振り返り）
- 町を歩いて、場所（人）に近づいて **調べると** その枠を消費＝他へは行けない
- 予定なしのスキップ（枠は消費する）
- 場所に紐づくキャラの関係値を +1 する仮ロジック（`GameState.affinity`）
- 40日を越えると「世界の終わり」→ もう一度夏を始める（周回）

## 操作

| キー | 動き |
|------|------|
| WASD / 矢印キー | 移動 |
| E（Space / Enter） | 調べる・カレンダーをめくる・周回リスタート |
| Q | 予定なしでスキップ（枠を消費） |

## 動かし方

1. **Godot 4.6** でこのフォルダ（`project.godot` のある場所）を開く。
2. 初回はアセットのインポートが走る（少し待つ）。
3. ▶ 実行（F5）でメインシーン `scenes/Town.tscn` が起動する。

> **見た目は仮です。** プレイヤーも場所も、いまは四角い「プレースホルダ」で描いています
> （アートが無くても動かせるように）。ドット絵は後から `Sprite2D` /
> `AnimatedSprite2D` / `TileMapLayer` に差し替えていきます。

> **日本語フォント**は `assets/fonts/NotoSansJP-Regular.ttf`（Noto Sans JP / OFL 1.1）を
> 同梱し、`project.godot` の `gui/theme/custom_font` で全体に適用しています。

## ファイル構成

```
project.godot              プロジェクト設定（Autoload登録・メインシーン・フォント）
autoload/
  GameState.gd             ★状態の中心。日付・時間帯・好感度・フラグ＋一日を進める状態機械
data/
  Locations.gd             町の「場所」定義（id/名前/キャラ/マップ座標）
scenes/
  Town.tscn / Town.gd      町マップ（メインシーン）。プレイヤー・場所・HUD をまとめる司令塔
  Player.tscn / Player.gd  2D操作キャラ（CharacterBody2D）。WASD/矢印で歩く
  LocationSpot.tscn / .gd  場所（Area2D）。近づいて調べると枠を消費
  HUD.tscn / HUD.gd         画面手前のカレンダー表示＋操作プロンプト
assets/fonts/
  NotoSansJP-Regular.ttf    日本語フォント（OFL 1.1）
```

## 設計の考え方（初心者向けメモ）

ノベルUIから2D探索に変えても、**日付や好感度を持つ `GameState` は一切変えていません。**
これが「状態（モデル）と表示（ビュー）を分ける」設計の効き目です。

- **状態は `GameState` が唯一の持ち主。** 日付・時間帯・好感度・フラグと、
  `午前 → 午後 → 夜 →（めくる）→ 翌朝` を進める状態機械。ここはUIを知らない。
- **見せ方はビューが担当。** ボタンで選ぶ／歩いて調べる、はどちらも「行動枠を消費する
  入力」を送る手段の違いに過ぎない。今回は `Town.gd` がその役。
- **シグナルで疎結合に。** 状態が変わると `GameState` が `day_changed` /
  `phase_changed` を emit し、`HUD` などが受けて表示し直す。UIを増やしても購読するだけ。
